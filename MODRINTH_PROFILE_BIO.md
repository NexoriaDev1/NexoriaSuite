# Hey there, I'm NexoriaDev! 

I build high-performance, asynchronous server architectures, developer APIs, and gameplay mechanics for modern Minecraft servers (**Paper**, **Purpur**, and **Folia** on **Java 25+**).

---

### The NexoriaSuite Ecosystem
**NexoriaSuite** is a cohesive, modular collection of 30+ lightweight plugins built with a zero-bloat philosophy:

* **Native Folia & Multi-threading**: Zero main-thread blocking operations.
* **Adventure MiniMessage**: Dynamic formatting, gradients, and interactive hover/click events.
* **High Throughput**: Thread-safe concurrency with `ConcurrentHashMap` and virtual thread execution.

---

### Key Projects
* **NexoriaCore**: Async scheduler bridge & foundational API engine.
* **NexoriaEconomy**: Multi-currency economy suite with Vault integration.
* **NexoriaSync**: Real-time cross-server inventory and player synchronization via Redis.
* **NexoriaMenu**: Reactive inventory GUI framework with auto-pagination.
* **NexoriaCombat**: High-intensity PvP combat logger and damage indicators.
* **NexoriaClaims**: Lightweight chunk protection with visual particle bounds.
